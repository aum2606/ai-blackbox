# ADR-010 — Phase 2 builds only what runs produce

**Status:** Accepted for Phase 2.
**Context:** ADD §13 Phase 2 lists token IDs, a `measurements` table and immutable experiment manifests next to the artifact store and AI Trace IR. Nothing produces them yet: the Phase 1 fixture model has no tokenizer (ADR-009), measurements come from neural capture (Phase 3) and experiments from the runner (Phase 5). Rules §1 forbid tables and interfaces without a real producer.
**Decision:** Phase 2 delivers the AI Trace IR v0.1 envelope with two typed event payloads, a checksummed content-addressed artifact store with quota, artifact lineage, and artifact references on documents and invocations. Token IDs and measurements move to Phase 3. Experiments, attempts and manifests move to Phase 5. Prompt text is stored as an artifact only on per-run opt-in (ADR-007).
**Alternatives:** (a) build the full ADD list now with synthetic data: schema that nothing writes to; (b) add a real tokenizer now: needs the Phase 3 model choice first.
**Consequences:** The Phase 2 exit test (trace → invocation → artifact lookup by ID) is met with real data. Phase 3 and Phase 5 each add their own migration.
**Validation:** Phase 2 exit test in `tests/e2e/test_phase2_exit.py`.
**Rollback:** Migration 0002 downgrades cleanly; no Phase 1 behaviour changes.
